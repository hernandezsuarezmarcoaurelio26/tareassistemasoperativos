# Tarea1
Escribir, compilar y ejecutar un programa para la creación de un proceso utilizando la llamada al sistema fork(), en el cual el proceso padre debe de imprimir números del uno al 10,000 y el proceso hijo números del 10,000 al uno.
# Tarea2
Escribir, compilar y ejecutar un programa para la creación de un hilo utilizando la biblioteca pthread en el cual el proceso principal debe de imprimir números del uno al 10,000 y el hilo números del 10,000 al uno.
# Tarea3 
Escribir, compilar y ejecutar un programa para la creación de dos hilos utilizando la biblioteca pthread en el cual cada hilo imprime una cuenta del 1 al 10000. Cuando un hilo llegue a 4000 este ya no debe ser interrumpido hasta llegar a 6000 (sección crítica). Se deben utilizar semáforos para la implementación. 
# Tarea4
Escribir, compilar y ejecutar un programa para la implementación del problema de productor-consumidor con múltiples productores y consumidores (dos de cada uno) utilizando la biblioteca pthread .
# Tarea5
Escribir, compilar y ejecutar un programa que implemente el problema de la cena de los filósofos, utilizando la biblioteca pthread.
